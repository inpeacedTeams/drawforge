# DrawForge

Веб-редактор технических чертежей, который строит 3D-модель по проекциям. Работает в браузере, без установки и без сторонних библиотек.

**Открыть редактор:** [index.html](index.html) · **Презентация:** [presentation.html](presentation.html)

Если включить GitHub Pages в настройках репозитория, приложение откроется по адресу `https://inpeacedTeams.github.io/drawforge/`.

## Возможности

### Черчение
- Линия, прямоугольник, окружность, ломаная, замкнутый контур
- Привязка к сетке, размер фигуры видно прямо у курсора
- Панель свойств: вписал ширину 100 и высоту 50, геометрия сразу обновилась
- Инструмент простановки размеров, отмена и повтор действий
- Масштабирование колёсиком, перемещение листа зажатым колёсиком

### Два режима работы
- **Один лист** — свободное черчение на чистом листе с сеткой
- **По проекциям** — отдельные рабочие листы: фронтальная, вид сверху, вид сбоку

### Показать вместе
Собирает все проекции на одном листе по правилам черчения: вид сверху над фронтальной, вид сбоку справа, между ними линии проекционной связи. Компоновка считается по реальным габаритам, поэтому виды не накладываются друг на друга.

### Разметка размеров
Одна кнопка проставляет размеры по всему чертежу: ширину и высоту с выносными линиями и стрелками, диаметры окружностей со знаком ⌀, длины линий. Единицы переключаются между миллиметрами и сантиметрами.

### Создать 3D
- Форма берётся из замкнутого контура фронтальной проекции, в том числе собранного из отдельных линий
- Глубина считывается из вида сверху, а при его отсутствии из вида сбоку
- Окружности внутри контура вычитаются как отверстия
- Просмотр с вращением мышью и фиксированными видами: изометрия, спереди, сверху, сбоку

### Экспорт
- Оформленный лист А4 с рамкой, штампом и автоподбором масштаба: PDF, SVG, PNG
- Чертёж: SVG, DXF, PNG
- Модель: STL для 3D-печати
- Проект: JSON

### Обучение
Пошаговый тур из 11 шагов с подсветкой элементов интерфейса. Запускается при первом открытии, потом доступен по кнопке со знаком вопроса.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `V` | выбор |
| `L` | линия |
| `R` | прямоугольник |
| `C` | окружность |
| `P` | ломаная |
| `G` | контур |
| `D` | размер |
| `Delete` | удалить выбранное |
| `Ctrl+Z` / `Ctrl+Shift+Z` | отменить / повторить |
| `Ctrl+S` | сохранить проект в браузере |
| `Esc` | сбросить выбор, закрыть окно |

В окне 3D: `1` спереди, `2` сверху, `3` сбоку, `0` изометрия, `Esc` возврат к чертежу.

## Как это сделано

Чистый HTML, CSS и JavaScript, отрисовка через Canvas 2D. Сторонних библиотек нет вообще, включая 3D: рендер написан с нуля, он строит грани тела, отсекает невидимые, сортирует по глубине и добавляет освещение.

С нуля также написаны: геометрическое ядро с привязками и попаданием курсора по фигуре, поиск замкнутых циклов в наборе линий обходом графа, генератор чертёжного листа А4 с подбором масштаба из стандартного ряда.
