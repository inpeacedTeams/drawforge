# DrawForge

Веб-редактор технических чертежей, который строит по ним 3D-модель. Работает в браузере, без установки, без сторонних библиотек.

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Само приложение. Откройте двойным кликом. |
| `presentation.html` | Презентация проекта для защиты. Листается стрелками. |

## Возможности

- Линия, прямоугольник, окружность, ломаная, замкнутый контур, размерная линия
- Привязка к сетке, панорамирование и масштабирование листа
- Точные размеры числом: вписали ширину 100 и высоту 50, фигура сразу стала такой
- Автоматическая разметка размеров по всему чертежу, переключение мм и см
- Два режима работы: один лист или три проекции (фронтальная, вид сверху, вид сбоку)
- «Показать вместе»: все проекции на одном листе по правилам, с линиями проекционной связи
- «Создать 3D»: форма берётся из фронтальной проекции, глубина из вида сверху или сбоку, окружности внутри контура становятся отверстиями
- Просмотр модели: вращение мышью, виды спереди, сверху, сбоку, изометрия, каркасный режим
- Экспорт: лист А4 с рамкой, штампом и честным масштабом в PDF и SVG, а также PNG, DXF, JSON и STL для 3D-печати
- Обучающий тур из 11 шагов с подсветкой элементов интерфейса
- Отмена и повтор действий, сохранение проекта в памяти браузера

## Как работает построение объёма

1. В наборе фигур ищется замкнутый контур. Если контур собран из отдельных линий, он находится обходом графа по точкам соединения.
2. Контур приводится к правильному направлению обхода, отверстия к обратному.
3. Строятся грани: передняя, задняя и боковые стенки по каждому ребру.
4. Невидимые грани отсекаются по нормали, остальные сортируются по глубине и заливаются с учётом освещения.

Весь 3D-рендер написан вручную на Canvas 2D, поэтому приложение не зависит от внешних библиотек и работает офлайн.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `V` | Выбор |
| `L` | Линия |
| `R` | Прямоугольник |
| `C` | Окружность |
| `P` | Ломаная |
| `G` | Контур |
| `D` | Размер |
| `Delete` | Удалить выбранное |
| `Ctrl+Z` | Отменить |
| `Ctrl+Shift+Z` | Повторить |
| `Ctrl+S` | Сохранить проект |
| `Esc` | Отменить действие или закрыть окно |

В окне 3D: `1` спереди, `2` сверху, `3` сбоку, `0` изометрия, `Esc` назад к чертежу.

## Технологии

HTML, CSS, чистый JavaScript, Canvas 2D. Ни одной зависимости.
