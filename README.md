# DrawForge

Веб-редактор технических чертежей, который превращает проекции в 3D-модель прямо в браузере.

**Открыть приложение:** https://inpeacedteams.github.io/drawforge/

**Презентация проекта:** https://inpeacedteams.github.io/drawforge/presentation.html

Проект рассчитан на школьников и начинающих: интерфейс полностью на русском, без нагромождения кнопок как в профессиональных CAD-программах.

**Автор:** Руденко Егор · **Руководитель:** Зеленова Екатерина Александровна · **Школа:** КСОШ №2

## Быстрый старт

Откройте ссылку выше или скачайте репозиторий и запустите `index.html` двойным кликом. Установка не нужна, интернет не нужен, зависимостей нет.

## Возможности

**Черчение**
- Линия, прямоугольник, окружность, ломаная, замкнутый контур
- Привязка к сетке, подсказка размера рядом с курсором
- Панель свойств: вписал ширину 100 и высоту 50, фигура сразу стала такой
- Отмена и повтор действий, сохранение проекта в браузере

**Два режима работы**
- «Один лист»: чистый лист, рисуйте что угодно
- «По проекциям»: фронтальная, вид сверху и вид сбоку как отдельные листы одной детали

**Показать вместе**

Все проекции собираются на одном листе по правилам черчения: вид сверху над фронтальной, вид сбоку справа, между ними линии проекционной связи.

**Разметка размеров**

Одна кнопка проставляет размеры по всему чертежу: ширину и высоту со стрелками и выносными линиями, диаметры отверстий со знаком диаметра. Переключение миллиметров и сантиметров.

**Создание 3D**
- Форма берётся из фронтальной проекции, включая контур, собранный из отдельных линий
- Глубина считывается из вида сверху, а если его нет, то из вида сбоку
- Окружности внутри контура становятся отверстиями в теле
- Просмотрщик с вращением мышью и готовыми видами: изометрия, спереди, сверху, сбоку

**Экспорт**
- Лист А4 с рамкой, штампом и автоподбором масштаба: PDF, SVG, PNG
- Чертёж: SVG, DXF, PNG
- Модель: STL для 3D-печати
- Проект целиком: JSON

**Обучение**

Пошаговый тур из 11 шагов с подсветкой элементов. Запускается при первом входе, потом доступен по кнопке со знаком вопроса.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `V` | Выбор |
| `L` | Линия |
| `R` | Прямоугольник |
| `C` | Окружность |
| `P` | Ломаная |
| `G` | Контур |
| `D` | Размер |
| `Delete` | Удалить выбранное |
| `Ctrl` + `Z` | Отменить |
| `Ctrl` + `Shift` + `Z` | Повторить |
| `Ctrl` + `S` | Сохранить проект |
| `Esc` | Отменить построение или закрыть окно |

В просмотрщике 3D: `1` спереди, `2` сверху, `3` сбоку, `0` изометрия, `Esc` назад к чертежу.

## Как устроено внутри

HTML, CSS и чистый JavaScript. Ни одной внешней библиотеки.

Написано с нуля:
- геометрическое ядро: привязки, попадание курсора по фигуре, границы объектов
- поиск замкнутых циклов в наборе линий обходом графа
- собственный 3D-рендер на Canvas 2D: построение граней, отсечение невидимых, сортировка по глубине, освещение
- генератор листа А4: рамка, штамп, масштаб из стандартного ряда 1:1, 1:2, 1:5 и далее
